# SCHRITT 7 – Steuerung mit der GUI verbunden

In diesem Schritt wurde das HauptFenster mit der Steuerung (`BuchSteuerung`) verknüpft.

Folgende Funktionen wurden umgesetzt:
- Beim Klick auf den Button `btnHinzufuegen` werden Eingaben aus den TextBoxen ausgelesen.
- Es wird ein neues Buch über die Steuerung erstellt und im Datenspeicher gespeichert.
- Die DataGridView wird aktualisiert und zeigt die aktuelle Bücherliste an.
- Beim Laden des Fensters wird die Bücherliste automatisch angezeigt.

Die Anwendung ist nun funktional und vollständig bedienbar.
