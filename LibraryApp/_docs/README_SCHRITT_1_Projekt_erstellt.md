# SCHRITT 1 – Projekt erstellt

Heute wurde das C#-Projekt "LibraryApp" in Visual Studio angelegt.

Es wurde außerdem folgende Projektstruktur vorbereitet:

- Ordner `Modelle` für Datenmodelle
- Ordner `Steuerung` für die Steuerungslogik (Controller)
- Ordner `Daten` für die Datenverwaltung (Repository)
- Ordner `Ansichten` für die grafische Oberfläche (View)

Das Projekt ist nun bereit für die Implementierung der Basisklassen.
