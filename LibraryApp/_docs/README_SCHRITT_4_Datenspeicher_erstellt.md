# SCHRITT 4 – Datenspeicher erstellt

Im Ordner `Daten` wurde die Klasse `BuchSpeicher` angelegt.

Sie dient als Repository für die Verwaltung der Buchdaten. 
Die Klasse hält eine interne Liste von `Buch`-Objekten und stellt Methoden bereit, um Bücher hinzuzufügen, abzurufen und zu löschen.

Dies trennt die Datenhaltung sauber von der Steuerungslogik und der Benutzeroberfläche (MVC-Prinzip).
