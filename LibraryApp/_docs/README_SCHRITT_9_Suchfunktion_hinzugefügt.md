# SCHRITT 9 – Suchfunktion hinzugefügt

Es wurde eine Such- und Filterfunktion implementiert.

Neue Elemente in der Benutzeroberfläche:
- TextBox `txtSuche`
- Button `btnSuchen`
- Button `btnAlleAnzeigen`

Die Methode `Suche()` in `BuchSteuerung` filtert Bücher nach Titel oder Autor.
Damit kann der Benutzer die Liste gezielt durchsuchen.
