# SCHRITT 5 – Steuerung erstellt

Im Ordner `Steuerung` wurde die Klasse `BuchSteuerung` angelegt.

Die Steuerung vermittelt zwischen der Benutzeroberfläche und dem Datenspeicher.
Sie enthält Methoden zum Hinzufügen, Abrufen und Löschen von Büchern.

Dies trennt die Geschäftslogik von der Darstellung und der Datenhaltung (MVC-Prinzip).
