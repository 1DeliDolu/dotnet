# SCHRITT 2 – Basismodell erstellt

In diesem Schritt wurde die abstrakte Klasse `Basismodell` im Ordner `Modelle` angelegt.

Zweck der Klasse:
- Sie stellt eine gemeinsame Eigenschaft `Id` für alle zukünftigen Datenmodelle bereit.
- Die Klasse ist abstrakt und kann daher nicht direkt instanziiert werden.
- Diese Klasse ermöglicht Vererbung (Inheritance) und unterstützt eine saubere OOP-Struktur.
