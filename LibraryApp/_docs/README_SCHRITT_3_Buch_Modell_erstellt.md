# SCHRITT 3 – Buch-Modell erstellt

Im Ordner `Modelle` wurde die Klasse `Buch` angelegt.
Diese Klasse erbt von `Basismodell` und repräsentiert ein Buch in der Anwendung.

OOP-Konzepte in diesem Schritt:
- **Vererbung:** `Buch` nutzt die geerbte Eigenschaft `Id` aus `Basismodell`.
- **Kapselung:** Der Titel wird durch ein privates Feld `_titel` geschützt und über eine Property mit Datenkontrolle gesetzt.

Die Klasse ist nun bereit zur Verwendung in der Datenverwaltung und Steuerungslogik.
