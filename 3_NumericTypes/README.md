# Sayılar ve Numerik Türler

Bu konu C#'ta tam sayılar ve ondalıklı sayılarla çalışmayı özetler:

- `+`, `-`, `*`, `/` operatörleriyle temel dört işlem
- Parantezlerle işlem önceliğini kontrol etme
- Bölme işlemlerinde bölüm ve kalan hesaplama
- `int.MinValue`/`int.MaxValue` ile sınırları ve taşmayı inceleme
- `double` türünün aralığını ve yuvarlama hatalarını görselleştirme

Dersi tek başına denemek için:

```bash
dotnet run --project 3_NumericTypes/NumericTypes.csproj
```
