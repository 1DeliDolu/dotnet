# List Koleksiyonları

Bu konu `List<T>` üzerinden koleksiyonları yönetmeyi gösterir:

- Öğeleri yineleyerek string listelerini yazdırma
- `Add`/`Remove` ile liste boyutunu esnek biçimde değiştirme
- Indeksler ve `Count` özelliğiyle öğelere erişme
- `IndexOf` ve `Sort` ile arama ve sıralama yapma
- Fibonacci dizisinin ilk 20 elemanını üreten tamsayı listesi

Çalıştırmak için:

```bash
dotnet run --project 5_ListCollections/ListCollections.csproj
```
