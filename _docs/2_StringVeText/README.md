# String ve Text

Bu bölümde C# string API'lerinin sık kullanılan yönlerine kısa bir tur yapıyoruz:

- string interpolasyonu ile formata uygun mesaj oluşturma
- `Split`/`Join` gibi yardımcılarla metin normalleştirme
- `Contains`/`Replace` gibi API'lerle arama ve dönüştürme
- Sayısal değerleri kültüre duyarlı biçimlerle yazıya dökme
- `StringBuilder` kullanarak çok satırlı içerik üretme
- `Span<char>` üzerinden sabit uzunluktaki metni dilimleme

Uygulamayı doğrudan bu konu için çalıştırmak isterseniz:

```bash
dotnet run --project 2_StringVeText/StringVeText.csproj
```
