# Şartlar ve Döngüler

Bu konu `if` deyimleri ve döngü yapılarıyla C# kontrol akışına hızlı bir giriş sunar:

- `if` ve `else` ile koşullu dallanma
- `&&` ve `||` operatörleriyle bileşik koşullar yazma
- `while`, `do/while` ve `for` döngüleriyle tekrar eden işleri yürütme
- İç içe döngülerle matris benzeri çıktılar üretme
- `for` + `if` ile 1-20 arası 3'e bölünebilen sayıların toplamını bulma

Konuya özel örnekleri görmek için:

```bash
dotnet run --project 4_SartlarVeDonguler/SartlarVeDonguler.csproj
```
